How this works: every signature on the Ploxi platform is recorded as an entry in a hash chain. Each entry's fingerprint is derived from the previous one, so altering or removing any record breaks the chain visibly. Ploxi publishes the chain to this public repository daily, dated by GitHub - past records cannot be quietly rewritten. The full specification is in SPEC.md; the verification logic is open source in open/chain-verification.ts.
